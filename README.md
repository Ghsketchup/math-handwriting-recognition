# تطبيق التعرف على الكتابة اليدوية الرياضية
## Math Handwriting Recognition for Teachers

### 🎯 المميزات الرئيسية

✅ **تعرف الكتابة اليدوية الرياضية** - تحويل الرسومات اليدوية إلى معادلات رياضية
✅ **محرك رياضي داخلي كامل** - لا يحتاج اتصال بالإنترنت
✅ **تحويل إلى LaTeX و MathML** - صيغ رياضية قياسية
✅ **رسم التوابع ديناميكياً** - رسوم بيانية فورية
✅ **تحليل المعادلات** - خطوات الحل والتبسيط
✅ **دعم اللغة العربية** - واجهة عربية كاملة
✅ **Offline تماماً** - كل شيء محلي على الجهاز
✅ **مخصص لأساتذة الرياضيات** - أدوات تدريسية متقدمة

### 🛠️ التقنيات المستخدمة

- **اللغة**: Kotlin
- **الواجهة**: Jetpack Compose
- **معالجة الصور**: OpenCV للـ Android
- **نموذج التعرف**: TensorFlow Lite ONNX Runtime
- **محرك الرياضيات**: SymPy Port + Custom Math Engine
- **رسم الرسوم البيانية**: MPAndroidChart + Custom Canvas
- **قاعدة البيانات**: Room Database
- **النماذج المحلية**: تطبيق الأوزان مباشرة

### 📱 المتطلبات

- Android 8.0+ (API 26)
- ذاكرة RAM: 2GB+
- مساحة تخزين: 200MB للنماذج المدمجة

### 🚀 البدء السريع

```bash
git clone https://github.com/Ghsketchup/math-handwriting-recognition.git
cd math-handwriting-recognition
./gradlew build
./gradlew installDebug
```

### 🎨 الميزات الرئيسية بالتفصيل

#### 1. لوحة الرسم التفاعلية
- رسم سلس وحقيقي
- دعم الضغط والسرعة
- محرر سكتات (Undo/Redo)
- تلميحات ذكية أثناء الرسم

#### 2. محرك التعرف
- معالجة الصور المتقدمة
- تصنيف الرموز الرياضية
- تحديد المعادلات المعقدة
- دعم الكسور والأس والجذور

#### 3. محرك الرياضيات
- تحليل المعادلات
- التبسيط الجبري
- حل المعادلات
- اشتقاق ومكاملة
- دعم الدوال المثلثية
- تحليل متعددات الحدود

#### 4. رسم التوابع
- رسوم بيانية ديناميكية
- تتبع الرسم في الوقت الفعلي
- تكبير وتصغير تفاعلي
- عرض الخصائص (النهايات، الحدود، etc)
